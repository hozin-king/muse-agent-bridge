# Handoff Pekerjaan

Folder ini adalah arsip opsional untuk handoff berbentuk dokumen. Status ringkas task tetap harus diperbarui di `../board/tasks.json` memakai `tools/collab.py handoff`.

## Konvensi

- Satu file per handoff: `YYYY-MM-DD-<task-id>.md`.
- Gunakan `../templates/handoff.md`.
- Sertakan bukti hasil: path file, commit, PR, dan hasil test.
- Jelaskan pekerjaan yang belum selesai dan satu langkah berikut yang paling konkret.
- Jangan memasukkan data pribadi, konteks privat, atau kredensial.

Handoff yang baik memungkinkan agent lain melanjutkan dari bukti tertulis, tanpa mengandalkan ingatan agent sebelumnya.
