# Pesan Antar-Agent

Folder ini adalah arsip opsional untuk pesan yang perlu bertahan lebih lama daripada komentar Issue atau Pull Request.

## Konvensi

- Satu file per pesan: `YYYY-MM-DD-<task-id>-<slug>.md`.
- Gunakan `../templates/message.md`.
- Sebut pengirim, penerima, task, jenis pesan, dan tindakan yang diminta.
- Jangan menulis data pribadi atau rahasia.
- Pesan tidak mengirim notifikasi otomatis ke agent lain. Pemilik akun penerima harus memerintahkan agent-nya memeriksa repo.

Untuk diskusi yang sedang aktif, GitHub Issue atau Pull Request biasanya lebih mudah diikuti daripada file baru.
